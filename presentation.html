The AI Pipeline

Each render is a sequenced, cached AI conversation.

CALL 1 · /api/analyze Claude Vision

Parse the floor plan

Returns structured JSON: every room's type, dimensions, normalized coords, color swatch, wet/dry classification. Outline-preserving — L-shapes stay L-shaped.

CALL 2 · /api/recommend Claude Reasoning

Pick the SCG BOM

Reasons over the curated catalog. Returns picks[] with SKU, room_id, qty, bilingual rationale — plus a material_summary fed into the render prompt.

CALL 3 · /api/generate Gemini + Claude Verify

Render + verify + retry

3-stage sub-pipeline: Gemini renders, Claude scores layout fidelity, Gemini retries once with corrective feedback if needed. See next slide.

CALL 4 · /api/restyle Gemini

Same layout, new look

Same camera, same walls, different design language. KV-cached — a returning user pays ~$0 to flip between the 6 styles.

Layout Fidelity · layout-accuracy branch

Schematic → Render → Verify → Retry.

Image-gen models excel at materials, lighting, mood — but struggle with strict spatial constraints. We extract maximum layout fidelity by giving Gemini a clean signal and grading its work.

  1. 3a · Generate
    Schematic
    Color-block reference rendered client-side
  2. 3a · Render
    Gemini render
    Photoreal isometric output
  3. 3b · Verify
    Claude scores
    Layout fidelity JSON: room count, outline, missing rooms
  4. 3c · Retry
    Conditional
    Below threshold → Gemini regenerates once with corrective feedback
Verify failures are non-fatal · the original render ships if Claude can't be reached

Schematic anchoring

The noisy original plan no longer competes for Gemini's attention — it sees one unambiguous spatial signal.

Coordinate-precise prompting

Exact normalized coords + a 12×8 ASCII grid, cross-referenced by room markers [1], [2], …

Honest framing
